# VS. Super Mario Bros. native port has moved

The project now lives at **https://github.com/jsp244/vs-smb-recomp**: the source, every release and the
guides.

This repository is only a bridge. Copies of the game from version 1.3.4 or older look here when their
Updates tab checks for a new version, so it carries one release, 1.3.5 (the same packages as the one at
the new address), which those copies can install. From 1.3.5 on, the game updates from the new address.
